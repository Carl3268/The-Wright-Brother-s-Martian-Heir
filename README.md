# Martian Heir

An interactive, bilingual storybook about NASA’s Ingenuity Mars Helicopter, created by **Aevum**.

Follow a little helicopter’s journey from Earth to its extraordinary flights on Mars.

## Features

- English and Vietnamese editions.
- Illustrated pages with book-style page turns.
- Responsive layouts for desktop, tablets and phones.
- MP3 narration with browser-voice fallback.
- Chapter navigation, mission notes and learning activities.

Some English recordings use different wording from the displayed text. Select a browser voice to hear the page text instead.

## Built With

HTML, CSS and vanilla JavaScript. No installation or build step is required.

## Main Files

- `index.html` — Vietnamese entry page.
- `index-en.html` — English entry page.
- `styles.css` — appearance and responsive layouts.
- `script.js` — navigation, languages and audio playback.
- `assets/` — images, fonts, logo and recordings.
- `AUDIO-MAPPING.csv` — recording-to-page mapping.

## Run Locally

Run this command inside the project folder:

```sh
python -m http.server 3000
```

Open http://localhost:3000 in your browser.

If audio does not start automatically, click **Listen**.

## Deployment

Deploy as a static website using Cloudflare. Keep `index.html` at the deployment root and preserve the folder structure.
